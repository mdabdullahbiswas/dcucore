ফাইলের লিংক|File link

“Anyone with the link” কীভাবে করবেন|How to set “Anyone with the link”
  1. Drive-এ ফাইলটিতে ডান-ক্লিক করুন (মোবাইলে ⋮ চাপুন), তারপর “Share” বেছে নিন।|In Drive, right-click the file (tap ⋮ on mobile) and choose “Share”.
  2. “General access”-এ “Restricted”-এর জায়গায় “Anyone with the link” বেছে নিন।|Under “General access”, change “Restricted” to “Anyone with the link”.
  3. ভূমিকা “Viewer” রাখুন। “Editor” দেবেন না, নইলে যে কেউ ফাইল বদলে ফেলতে পারবে।|Keep the role as “Viewer”. Do not choose “Editor”, or anyone could change your file.
  4. “Copy link” চাপুন এবং লিংকটি এখানে পেস্ট করুন।|Press “Copy link” and paste it here.

ফোল্ডার নয়, একটি ফাইলের লিংক দিন। একাধিক ফাইল হলে প্রতিটি আলাদা করে জমা দিন।|Submit a link to one file, not a folder. For several files, submit each one separately.

  • ফাইলটি শেয়ার করার অধিকার আমার আছে এবং এতে অন্য কারও কপিরাইট ভাঙা হচ্ছে না।|I have the right to share this file and it does not break anyone else’s copyright.
  • লিংকটি “Anyone with the link” ও “Viewer” সেটিংয়ে আছে।|The link is set to “Anyone with the link” with “Viewer” access.
